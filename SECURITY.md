# Security and Safety Policy

## Safety & Privacy by Design

OffLoop AI is designed with physical safety and digital privacy as non-negotiable foundations:

1. **Anti-Distracted Walking:** The UI is designed for screen-light interaction. Navigation relies on environmental landmarks, compass headings, and memory clues—not turn-by-turn map-gazing while crossing streets.
2. **Local-First Location Data:** User location coordinates are evaluated on-device for geofencing proximity. Historical breadcrumb GPS traces are never uploaded to remote servers.
3. **No Trespassing or Hazardous Quests:** AI quest prompts are strictly bounded to public, free, and designated pedestrian spaces (parks, plazas, public art, historical plaques). Nighttime explorations and restricted areas are explicitly filtered out.
4. **Emergency Override:** Users can exit any quest or focus session at any time with an instant tap. Emergency calls (911/112) and essential system navigation are never blocked.
5. **No Forced Socials or Stranger Photography:** Quests never mandate approaching strangers or photographing identifiable people.

## Reporting a Vulnerability

If you discover a security vulnerability or safety hazard in OffLoop AI, please report it responsibly by opening a confidential GitHub Security Advisory or emailing `security@offloop.ai`.
