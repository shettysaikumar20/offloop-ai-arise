## 🌌 The Concept

**OffLoop AI: ARISE** is an ultra-lightweight, desktop-first quest, productivity, and self-improvement web application inspired by the supernatural **"System"** interface from *Solo Leveling*. 

It transforms your daily real-world chores, deep study sessions, physical workouts, and digital detox habits into high-stakes **Hunter Quests**, **Dungeon Raids**, and **Rank Promotions** — running 100% locally in your browser with zero bloat and zero telemetry.

## ⚡ Key Highlights & System Features

### 1. 🔮 First-Time Hunter Awakening Protocol
- **Interactive RPG Onboarding**: Staged 3-step awakening sequence on first launch.
- **Hunter Customization**: Name your hunter and assign your custom title.
- **Choose Your Discipline**:
  - 🛡️ **Iron Will & Digital Detox** (+2 Discipline bonus)
  - 🗡️ **Physical Vessel Awakening** (+2 Strength bonus)
  - 🔮 **Arcane Architect & Scholar** (+2 Intelligence bonus)
  - ⚡ **Temporal Sentinel** (+2 Endurance bonus)
- **First Quest Grant**: Instantly receive your customized E-Rank Awakening Quest and +75 starting XP.
- **Agency**: Skip or replay the awakening ritual at any time from System Settings.

### 2. ⚔️ Quest Gates & Mission Dispatch
- **Daily Conditioning Protocols**: Physical workouts, scholar's mental fortification, screen severance shields, deep work strikes.
- **Weekly Gates**: Extended trials that test consistency across multiple days.
- **Custom Quest Registration**: Create custom real-world missions with selectable difficulty (E/D/C/B/A/S), stat bonuses, and XP payouts.
- **Live Completion Dynamics**: Animated card border flashes, floating `+XP` rewards, audio confirmation, and streak counters.

### 3. 🗝️ Dungeon Challenges (Productivity Raids)
Multi-phase timed missions designed to defeat real-world procrastination before the timer expires:
- **Gate of the Cluttered Chamber (D-Rank — 25 Min)**: Desk cleanup, hydration, tab purge.
- **Red Gate: The Procrastination Labyrinth (B-Rank — 45 Min)**: Identify dread task, break into angles, strike down the deliverable.
- **Monarch's Citadel of Transcendent Craft (S-Rank — 75 Min)**: Full sensory lockdown, blueprint design, deep work surges.

### 4. ⏳ Focus Sanctum (Pomodoro Temporal Barrier)
- **Presets**: 15m Sprint, 25m Pomodoro, 45m Deep Work, 60m Flow Block, 90m Monastic.
- **Hardware-Accelerated Circular Timer**: SVG circular countdown with animated stroke dashoffset and calm breathing aura.
- **Session History Log**: Automatic tracking of focus minutes, task titles, and XP rewards.
- **Pure Local Execution**: Zero blocking of other Windows apps.

### 5. 👥 Shadow Companions & Echoes
Original unlockable companion manifestations born from past self-discipline:
- **Tenebris, Blade of Conviction** (Unlocks at Level 5 — *+5% Quest XP*)
- **Umbra, Silent Scholar** (Unlocks at 5 Focus Sessions — *+10% Focus XP*)
- **Vortex, Temporal Sentinel** (Unlocks at 7-Day Streak — *Streak degradation protection*)
- **Ignis, The Unyielding Core** (Unlocks at 25 Quests — *+15% bonus XP & raid buffs*)
- **Nocturne, The Void Sovereign** (Unlocks at S-Rank — *+25% All XP, Monarch Aura*)

### 6. 🏆 Achievements & Hunter Feats
- Track daily streaks, lifetime focus minutes, dungeon clear counts, and rank ascensions.
- Real-time progress bars with animated light shimmer effects across unlocked badges.

### 7. 🔈 Zero-Asset Synthesized Audio Engine
- Crystal system pings, level-up surges, rank promotion fanfares, and sanctum gongs generated in real time using the browser's native **Web Audio API**.
- 0 MB audio downloads, instant response, one-click mute toggle.

### 8. 💾 Local-First Persistence & Backups
- Stored reliably in versioned `localStorage` (`offloop_arise_v1`).
- One-click JSON backup export and instant JSON restore.

## 🚀 Quick Start Guide

### Prerequisites
- Node.js 18+ (tested on Node v20/v22)
- Any modern desktop web browser (Chrome, Edge, Firefox, Brave)

### 1. Launch the Web Application
```bash
# Clone the repository
git clone https://github.com/shettysaikumar20/offloop-ai-arise.git
cd offloop-ai-arise/frontend

# Install dependencies
npm install

# Start development server
npm run dev
```

Or run the convenient root script:
```powershell
# Windows PowerShell
.\scripts\run_web.ps1
```
```bash
# Linux / macOS
chmod +x ./scripts/run_web.sh && ./scripts/run_web.sh
```

Open your browser to: **[http://localhost:5173](http://localhost:5173)**
